Política de privacidade

Última atualização: 02/11/2026.

O que coletamos

O Tudo que Preciso não tem cadastro, login, carrinho nem pagamento. Não pedimos nem armazenamos nome, e-mail, telefone, endereço ou dados de cartão.

Favoritos

Quando você marca um produto com o coração, essa lista fica salva apenas no seu próprio navegador (armazenamento local). Ela não é enviada para nós. Você pode apagá-la limpando os dados do site no seu navegador.

Links para o Mercado Livre

Os produtos levam ao Mercado Livre por links de afiliado. Ao clicar, você passa a navegar no site do Mercado Livre, que tem sua própria política de privacidade. O Mercado Livre pode usar cookies para registrar que a visita veio deste site e, se houver compra, pagar uma comissão. Isso não muda o preço para você.

Estatísticas de visita

Podemos usar ferramentas de estatística (como o Google Analytics) para entender, de forma agregada, quantas pessoas visitam o site e quais páginas são mais vistas. Essas ferramentas podem usar cookies. Você pode bloqueá-los nas configurações do seu navegador.

Compartilhamento no WhatsApp

O botão de compartilhar apenas abre o WhatsApp com uma mensagem pronta contendo o nome e o link do produto. Nada é enviado sem a sua ação.

Seus direitos (LGPD)

Como não coletamos dados pessoais diretamente, não mantemos cadastro sobre você. Para dados tratados pelo Mercado Livre, use os canais do próprio Mercado Livre.

Este site contém links de afiliado. Podemos receber comissão por compras feitas pelos links, sem custo extra pra você. As compras são feitas diretamente no Mercado Livre.
